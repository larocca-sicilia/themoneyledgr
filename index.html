ShortsFabrik

A private desktop tool that produces and uploads short educational finance videos for the YouTube channel The Money Ledgr.

What it does

  • Creates short videos locally on the developer's own computer.
  • Uploads finished videos to the developer's own YouTube channel using the YouTube Data API (YouTube API Services).
  • Sets the title, description, tags and a scheduled publish time for each upload.

Who can use it

ShortsFabrik is not a public service. It is not offered, sold or distributed to anyone. It is used only by its developer, for one YouTube channel that the developer owns.
