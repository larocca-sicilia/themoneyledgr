2. About ShortsFabrik

ShortsFabrik is a private desktop application used only by its developer to upload videos to the developer's own YouTube channel. It is not offered to the public and has no other users.

3. Use of YouTube API Services

ShortsFabrik uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

4. What data is accessed and how it is used

  • Permission to upload videos (scope youtube.upload): used only to upload videos created by the developer to the developer's own channel.
  • Read-only channel information (scope youtube.readonly): used only to display the name of the connected channel so the developer can confirm the connection.

No data of other YouTube users is accessed. No viewer data, comments or analytics are collected.

5. Storage

The OAuth access token and refresh token are stored only locally on the developer's own computer. No data is sent to any server other than Google's / YouTube's own APIs. No data is stored in the cloud by ShortsFabrik.

6. Sharing

ShortsFabrik does not sell, share, transfer or disclose any data to third parties.

7. Cookies and tracking

ShortsFabrik and this website do not use cookies, analytics or tracking.

This website is hosted on GitHub Pages (GitHub, Inc., 88 Colin P Kelly Jr St, San Francisco, CA 94107, USA). When you visit it, GitHub may process technical data such as your IP address in server logs for security and operation. See the GitHub Privacy Statement.

9. Revoking access

Access granted to ShortsFabrik can be revoked at any time via the Google security settings page: security.google.com/settings/security/permissions. Deleting the local token file also removes all stored access.
